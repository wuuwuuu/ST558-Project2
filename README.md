NFL Data Explorer

About: This app lets you explore NFL data from the 2009-2018 seasons by allowing the user to subset plays,
       visualize filtered data, build contingency tables, look at summary statistics, and create/view different plots.

Use: 
- To use the app the data must first be downloaded from this link https://www.kaggle.com/datasets/maxhorowitz/nflplaybyplay2009to2016/data and 
     extra code will be needed to save this as an RDS file or manipulated to fit the variable names in the file. The app can also be used more simply
     by visiting the link https://anthonywu.shinyapps.io/nfl-explorer/

Tips on usage:
- The sliders and variables on the left sidebar are used to subset the data for filtering. The sliders are dynamic meaning the ranges will change with
  the variable being selected in the drop-down boxes. These filters will affect the rows that are looked at in each of the data exploration tabs as well
  as the table in the data download tab.
- Each of the data exploration tabs allows the user to view different types of plots and statistics, the categorical tab has contingency tables and bar charts,
  the numeric tab has histograms, boxplots, and summary statistics, and the relations tab allows for heatmaps and scatterplots between numeric and categorical variables.
